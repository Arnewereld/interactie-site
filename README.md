# Operation Overgrowth

An interactive poster that behaves like a sci-fi camera feed. Click a glowing target (helmet, rifle, beam, mushrooms, canopy, boulder and more) and the camera flies in with an ENHANCE effect, letterbox bars, a lock-on reticle and synthesised sound. Click anywhere else to enhance that spot, use the arrows or ← → keys to fly between targets, Esc to pull back out, or press Play tour to watch it all like a film.

Plain HTML, CSS and JS with no build step. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works as is).
